# 文件夹皮肤生成器 · Folder Skin Generator

说出喜欢的角色、风格与场景，生成一整套协调的文件夹皮肤。支持只改一款、追加同系列，以及制作圣诞节、夏日海边等场景版本。

这是一个供 Codex 使用的 Skill，需要支持图像生成、图像参考和本地文件操作的运行环境。它不是独立生图服务；Python 脚本负责检查和打包，图片由宿主的图像工具生成。

## 能做什么

- **整套生成**：默认 6 款，通常 6–8 款；支持指定数量、尺寸、主题、角色、配色和参考图。
- **母版一致性**：先确定角色和构图，后续每款回到同一母版派生，减少风格漂移。
- **配饰、表情与动作变化**：让每款有不同的小情节，同时保留角色辨识度与文件夹造型。
- **自定义场景**：节日、季节、地点、活动及组合场景；默认通过配饰和装饰表达，外部保持透明。
- **单款修改与续作**：保留旧版本，只改指定款；同系列追加可超过原套装的 8 款。
- **检查与交付**：检查数量、实际像素尺寸、透明性与空图；提供浅深背景、小尺寸预览及图片 ZIP。

## 安装

下载本仓库 ZIP 并解压，把包含 `SKILL.md` 的整个目录命名为 `folder-skin-generator`，放入 Codex 的个人技能目录（默认 `~/.codex/skills/`，自定义配置时使用对应技能目录）。

安装后的目录应为：

```text
~/.codex/skills/folder-skin-generator/SKILL.md
```

然后在支持该 Skill 的 Codex 对话中调用 `$folder-skin-generator`。生图工具由宿主提供，默认使用内置图像工具，无需为普通调用配置 API 密钥；不在失败时自动切换收费 API。

## 使用示例

### 新建套装，先确认母版

```text
使用 $folder-skin-generator，生成一套6款原创小狗主题文件夹皮肤，
平面卡通风、多巴胺配色，每款有不同配饰、表情和动作。
先做一张母版让我确认。
```

### 沿用角色制作场景版

```text
沿用已确认的小狗母版，做6款圣诞节文件夹皮肤。
配色匹配圣诞元素，使用扁平插画和极简几何构图，保持透明背景。
```

```text
沿用这套角色做6款夏日海边主题，使用海蓝、珊瑚橙与沙滩黄，
加入遮阳帽、泳镜、贝壳、椰子等元素，先给我看场景母版。
```

### 修改、追加、换色

```text
第三款把围巾换成蝴蝶结，其他图片不要动。
沿用这套风格追加两款，分别用于工作和学习。
保留角色、配饰和动作，整套换成秋天配色。
```

不同对话中续作时，请提供原套装目录或母版和设计规范，确保能读取之前的设计。

## 工作方式

1. 整理需求和款式计划，确定整套固定项与可变项。
2. 制作或读取母版；要求先看样时等待用户确认。
3. 每款分别引用同一母版生成，不逐张串联，也不把拼版切割成单图。
4. 运行图片硬检查，并视觉比较角色、主体大小、风格、透明边缘和小尺寸辨识度。
5. 定向修复偏离款，保存终稿、预览、ZIP 和续作记录。

已有角色的场景衍生会保存原角色母版与场景母版的关联。原套装不会被场景版本覆盖。

## 交付内容

```text
pack/
├── source/              原始输出与母版
├── final/               独立透明 PNG
├── design-spec.json     款式、角色、场景、母版与版本记录
├── prompts.json         实际生成提示词（也可使用其他明确命名）
├── validation.json      程序检查与单独记录的视觉结论
├── 使用说明.txt
└── delivery/
    ├── final/           图片副本
    ├── preview.html     浅深背景、64/128/256像素预览
    ├── skins.zip        仅包含独立图片
    └── validation.json
```

独立打包脚本只创建 `delivery/` 部分；设计规范、提示词与视觉结论由执行 Skill 的助手维护。

## 本地检查与打包脚本

需要 Python 3.10+ 和 Pillow。建议使用独立环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

只读检查选定的终稿目录：

```bash
python scripts/validate_pack.py /path/to/pack/final \
  --count 6 --width 1024 --height 1024 \
  --output /path/to/pack/validation.json
```

生成可携带的预览与图片 ZIP：

```bash
python scripts/package_pack.py /path/to/pack/final \
  --count 6 --width 1024 --height 1024 \
  --output /path/to/pack/delivery
```

将数量与宽高替换成当前套装的实际目标。`delivery` 必须是尚不存在的新目录，且不能位于终稿目录内部。脚本不会缩放、修图或覆盖已有交付目录；检查不通过时不会创建交付包。移动预览时需连同其中的 `final/` 图片目录一起移动。

检查成功退出码为 `0`，检查失败为非零。警告仍需人工查看，例如图像内容接触画布边缘。

## 一致性的边界

- 默认目标为 1024×1024，生图工具可能输出其他尺寸；以实际文件检查为准。续作可沿用已认可母版的真实尺寸，不能悄悄把尺寸不符标成通过。
- 相同画布不代表文件夹主体大小完全相同。透明区域外接框仅用于辅助，主体比例需视觉检查。
- 有透明像素不代表边缘一定干净；风格、角色身份和场景辨识度不能由脚本自动证明。
- 参考图和母版约束可以减少漂移，不能保证逐像素一致。每款最多两次定向修复，失败会如实保留状态。
- “矢量插画风”指视觉风格，默认交付 PNG，不等于 SVG 等可编辑矢量源文件；生成结果可能残留轻微明暗或纹理。
- 不会自动替换电脑文件夹图标；ICNS、ICO 或系统安装操作需要另行指定。

已在小狗角色与圣诞场景各一套六款的实际使用中完成用户验收；这不代表所有角色、场景和生成服务状态均已验证。仓库仅包含通用规则和工具，不包含测试角色图片或私人文件。
